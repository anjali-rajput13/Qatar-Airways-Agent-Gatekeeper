# AI Prompt Log – Qatar Airways Agent Gatekeeper

## Project Overview
This project is a prototype of an AI Agent Gatekeeper for Qatar Airways. It demonstrates how an airline can control actions performed by AI agents on behalf of customers.

## Prompts Used During Development

1. Help me design an AI Agent Gatekeeper prototype for Qatar Airways that checks customer requests before an AI agent performs an action.

2. Create rules to allow registered agents to view flight fares and booking details, block unknown or revoked agents, and require customer confirmation for high-value bookings, changes and refunds.

3. Help me build a Python Streamlit application with a dashboard, agent registration, agent revocation, request submission and audit history.

4. Create a rules engine that returns ALLOW, ASK CUSTOMER or BLOCK, along with the applicable rule number and reason.

5. Add an agent registration system that records customer details, agent names and spending authorisation limits.

6. Add a revocation feature so that revoked agents cannot perform further actions.

7. Create an audit log that records request details, decisions, rule numbers, reasons and timestamps.

8. Help me test the application using six scenarios, including authorised requests, unknown agents, high-value bookings, revoked agents and refunds.

9. Help me identify and fix errors in the registration and revocation forms.

10. Help me organise the project files and upload the completed application to GitHub.

## AI Assistance
AI tools were used to support project planning, Python code development, debugging, testing and documentation. The final prototype was reviewed through practical test scenarios.
